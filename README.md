# Universo Interior

Site de Leovaldo Sena Barbosa. Cópia da versão publicada neste chat, commit de origem 512f7ea5e6ca271fa1a37bfd32d1133354d1ce39.

## Hospedagem
Envie index.html, os arquivos CSS/JS, catalogo.json e as pastas assets e ferramentas para a raiz pública do domínio (por exemplo public_html). Site estático, sem instalação ou banco de dados. Os caminhos começam em /; para hospedar numa subpasta, adapte o prefixo dos caminhos.

Os 23 questionários organizam as respostas e abrem o WhatsApp de Leovaldo para confirmação de envio. Não executam análises nem armazenam respostas no servidor.

Abra o site por um servidor HTTP; abrir index.html diretamente pode impedir o carregamento do catálogo.
